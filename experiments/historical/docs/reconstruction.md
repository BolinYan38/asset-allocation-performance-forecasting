# reconstruction.py：用已知股票行情估计策略收益

日期定位完成后，我们从历史行情取得目标日每只股票的实际收益，再利用策略的历史收益拟合股票系数，估计该策略的目标日收益。本文件提供112列基础特征和15列股票加权后的特征，供最终的 CatBoost 分类器使用。

## 1. 入口、数组与执行顺序

```python
base = ReturnReconstructor().features(data, raw)
sparse = SharedSparsePrior().features(data, raw)
```

`data` 是管理日期、股票行情和收益尺度的 `AllocationData` 对象，`raw` 是当前采样记录。`base` 每条记录112列，`sparse` 每条记录15列。学习得到的另外3列特征由 `stock_prior.py` 计算。

每个市场的 `data.panel()` 返回四个数组，详见 [data.md](data.md)。本文件使用下列名字：

| 名字 | 含义 |
|---|---|
| `public` | 市场交易日 × 股票，已经标准化的股票日收益 |
| `values` | 记录日期 × 20个历史日 × 策略，已经标准化的策略收益 |
| `positions` | 各记录日期在该市场交易日表中的下标 |
| `row_map` | 各日期、策略对应的输入行位置，缺少记录为 −1 |
| `query` | 当前处理的日期在面板中的行号 |
| `selected` | 当前日期实际存在的策略列号 |
| `position` | 当前日期的市场交易日下标，即 `positions[query]` |

若 `position=100`，当前20日历史取交易日下标81至100，目标日取101。本文所说前后多少天均按当前市场交易日计数。

基础特征的执行顺序为：

```text
features() 按市场、日期循环
  signals()
    当前20日岭回归
    pooled_history() 归并其他记录提供的历史，再拟合
    _shared_prior() 从各策略拟合系数中提取共同信息
    bridge_features() 保留记录来源，再联合拟合
  _overlap() 查后续记录中的目标日策略收益
填入历史收益、成交量、滚动统计
计算同日同组均值及排名，填入身份编号
```

## 2. ridge_predict()：所有收益估计共用的求解步骤

### 2.1 输入与有效历史日

`kernel` 是历史日之间的股票收益内积矩阵，`observed` 是历史日 × 策略收益矩阵，`cross` 是历史日与目标日的股票收益内积，`weights` 是各历史日的观测权重。`ridge` 是对系数的惩罚强度，默认0.7。

函数先按策略历史收益的缺失位置分组。相同缺失模式的策略共用一次矩阵求解。只有收益有值、且观测权重大于百万分之一的历史日参与拟合；少于4天时保留收益估计0、误差1。

### 2.2 线性方程与返回值

固定一个缺失模式，设保留历史日数为 n、策略数为 m。K 表示选出的 n × n 内积矩阵，Y 表示 n × m 策略收益矩阵，wᵢ 是第 i 个历史日的正权重，λ 是岭系数。D 为对角矩阵，其第 i 个对角元素为 λ/wᵢ，A 为待求的 n × m 系数矩阵。

$$
(K+D)A=Y,\qquad D_{ii}=\frac{\lambda}{w_i}.
$$

设 k 是 n 维目标日内积向量，上标 T 表示转置，目标日各策略的估计收益向量为：

$$
\widehat y=k^{\mathsf T}A.
$$

多个目标日可以作为 `cross` 的多列传入，共用 A。代码同时返回历史拟合的均方根误差。设 E 为历史残差矩阵，则：

$$
E=Y-KA=DA,\qquad
\operatorname{error}_j=\sqrt{\frac1n\sum_{i=1}^n E_{ij}^{2}},\quad j=1,\ldots,m.
$$

这里 j 是策略列号。这是使用全部有效历史拟合后的残差，当前窗口的留一日误差另在 `signals()` 中计算。

### 2.3 时间变化如何加入

`temporal` 提供历史时间 `times`、目标时间 `query_time` 和衰减长度 `length`。记第 i 个历史时间为 tᵢ、目标时间为 t★、衰减长度为 L，则替换：

$$
K_{ij}\leftarrow K_{ij}e^{-|t_i-t_j|/L},\qquad
k_i\leftarrow k_i e^{-|t_i-t_\star|/L}.
$$

i、j 在这里均为历史行号。L 越小，间隔较远的记录对共同拟合的影响越弱。附近历史拟合使用实际收益日作为时间，保留记录来源的拟合使用记录提交日作为时间。

## 3. signals()：当前20日的7列

### 3.1 三种岭系数的收益估计

设 p 为股票数。H 是当前有效历史日的股票收益矩阵，x 是已知的目标日股票收益向量，两者均由 `public` 取出后再除以股票数的平方根。于是 K=HHᵀ，k=Hx。

函数分别采用岭系数0.1、0.7、3.0，得到三列目标日策略收益估计。系数0.7的求解同时估计目标日前一天及后一天的收益，另得两列。

### 3.2 汇总留一日误差

这一步选取当前所选策略都具有收益数据的历史日。设剩余历史日数为 n，Y 为这些历史日的策略收益矩阵，Iₙ 为 n 阶单位矩阵。定义 B 为正则化内积矩阵的逆，E 为留一日误差矩阵：

$$
B=(HH^{\mathsf T}+0.7I_n)^{-1},\qquad E_{ij}=\frac{(BY)_{ij}}{B_{ii}}.
$$

i 表示被遮住的历史日，j 表示策略。Eᵢⱼ 等于第 i 日实际策略收益减去“排除第 i 日后重新拟合”的估计。

对每个策略沿历史日汇总，得到一列均方根误差：

$$
\operatorname{current\_loo\_error}_j
=\sqrt{\frac1n\sum_{i=1}^n E_{ij}^{2}}.
$$

`loo` 表示留一日验证。假设20天中19天的误差均为0.1，另一天为0.5，则这一列为 `sqrt((19×0.1²+0.5²)/20)`，约0.1483。多个历史日误差经过汇总，每条策略记录得到一个数。

### 3.3 目标日股票行情与历史的关系

`current_target_leverage` 直接由股票行情计算。沿用本节 H、x、B，代码取：

$$
v=\max(0,x^{\mathsf T}x-(Hx)^{\mathsf T}B(Hx)).
$$

v 是这一列的值。设 a 是 n 维历史日组合系数，二范数平方表示分量平方之和，则截断前的表达式等于：

$$
\min_a\left(\|x-H^{\mathsf T}a\|_2^2+0.7\|a\|_2^2\right).
$$

它衡量历史股票收益能多好地组合出目标日股票收益，同时惩罚过大的组合系数。目标日股票收益来自已对齐的历史行情，待估计的是策略收益。同日同组各策略共用这个行情指标。

| 配置名称 | 内容 |
|---|---|
| `current_ridge_01`、`current_ridge_07`、`current_ridge_30` | 三种岭系数的目标日收益 |
| `current_loo_error` | 各历史日留一日误差的均方根 |
| `current_target_leverage` | 本节定义的 v |
| `current_shift_minus1`、`current_shift_plus1` | 同一拟合得到的目标日前一天、后一天收益 |

## 4. pooled_history() 与附近历史的12列

### 4.1 把不同记录中的历史放到真实交易日上

取当前日期前后84个交易日以内、距离最近的至多9个记录日期，提取它们各自的20日收益。同一个真实交易日可能出现在多条记录中。

`pooled_history()` 将它们按实际收益日归并。每条来源记录的权重是其日期距离当前日期的指数衰减，衰减长度为48。对每个策略、每个收益日，分别累计“权重乘收益”和“有值记录的权重”，相除得到加权平均；目标日直接排除。

例如当前下标100的记录含81至100日，另一下标105的记录含86至105日。合并时86至100日有重复观测，101日为目标日而被排除，其余有值日期保留。102至105日可以参与拟合。

### 4.2 收益估计、误差和数量

归并后，每个收益日再按距离当前日期的远近加权，衰减长度为84。先估计固定股票系数的收益，再用15、60、240三档时间衰减估计收益。

`turnover_interpolation()` 根据换手率选择三档估计之间的位置。设 u 为换手率，缺失时取0.2，并设有效换手率 u₀、衰减长度 L：

$$
u_0=\max(u,0.02),\qquad L=\min(240,\max(15,0.75/u_0^2)).
$$

函数在对数长度15、60、240对应的三种收益估计之间做线性插值。例如 u=0.1 时 L=75，结果位于长度60与240的两个估计之间。

随后从当前20日岭回归的股票系数计算各股票的重要程度。拟合系数平方在策略间的均值越大，该股票得到的权重越高。用调整后的股票内积，再生成一列目标收益和一列历史拟合误差。

| 配置名称 | 内容 |
|---|---|
| `local_constant` | 固定股票系数的目标收益 |
| `local_daily_fast`、`local_daily_medium`、`local_daily_slow` | 长度15、60、240的时间变化模型收益 |
| `local_daily_turnover` | 依换手率插值的收益 |
| `local_adaptive_daily` | 调整股票重要程度后的收益 |
| `local_history_error` | 上一项在已有历史上的拟合误差 |
| `local_observation_days` | 归并后的交易日数量 |
| `local_strategy_coverage` | 当前策略在这些交易日有值的比例 |
| `public_next_market_mean` | 目标日各股票标准化收益的均值 |
| `public_next_market_std` | 上述收益的标准差 |
| `public_next_positive_fraction` | 目标日上涨股票比例 |

## 5. _shared_prior()：从同组策略系数提取信息，共6列

### 5.1 用更多历史拟合股票系数

调用 `pooled_history()`，日期半径改为260，最多取26条日期记录，归并权重衰减长度为100。归并后的实际收益日权重衰减长度为200。

设 H 为这些日期的股票收益设计矩阵，已除以股票数平方根；y 为一个策略的有效历史收益；W 为历史日权重构成的对角矩阵；P 为股票系数的惩罚矩阵。拟合股票系数 β 的方程是：

$$
(H^{\mathsf T}WH+0.7P)\beta=H^{\mathsf T}Wy.
$$

每种缺失模式使用对应历史行。有效历史少于4天的策略系数设零。

### 5.2 构造股票系数共同变化的矩阵

先令 P 为单位矩阵，得到各策略的系数。每个策略的系数再除以其有效历史收益标准差，分母下限0.1。将这些系数按列组成矩阵 U。

设 p 为股票数、m 为策略数、tr 表示对角元素之和，Iₚ 为 p 阶单位矩阵。先计算 C₀，再归一化为 C，最后与单位矩阵混合成 Q：

$$
C_0=\frac{UU^{\mathsf T}}m,\qquad
C=\frac{pC_0}{\max(\operatorname{tr}(C_0),10^{-12})},\qquad
Q=0.5I_p+0.5C.
$$

U 在这里直接相乘，代码没有先减去策略间的系数均值。C 的对角元素反映各股票系数大小，非对角元素反映两只股票系数一起出现的程度。

再分别令 P 等于 Q 的逆矩阵，以及以 Q 对角元素倒数构成的对角矩阵，得到两套新的股票系数。

| 配置名称 | 内容 |
|---|---|
| `long_ridge` | P 为单位矩阵时的目标收益 |
| `long_covariance_prior` | 使用 Q 的完整逆矩阵时的目标收益 |
| `long_diagonal_prior` | 只使用 Q 对角元素时的目标收益 |
| `long_covariance_error` | 完整矩阵方案的历史残差均方根 |
| `long_observation_days` | 归并后交易日数 |
| `long_prior_concentration` | `tr(C @ C) / max(tr(C)², 1e-12)`，衡量系数是否集中在少数共同方向 |

函数返回这6列、Q，以及第一次普通岭回归得到的股票系数矩阵 `mean`。后两个对象交给下一步使用。

## 6. bridge_features()：按记录来源联合拟合，共9列

选取前后84个交易日内最近的至多5条日期记录，每条取20日历史。同一实际收益日出现在多条记录时，各条观测分别保留。代码中的 `days` 是实际收益日，`times` 是每条观测所属的记录日期。

例如日期100和105都报告第95日的策略收益，两条观测的 `days` 都是95，而 `times` 分别是100、105。时间衰减按照100与105的距离计算，允许两条记录对应的股票系数不同。

来源记录的观测权重按距离当前日期衰减，长度为84。直接出现目标日收益的观测再乘5。

| 配置名称 | 内容 |
|---|---|
| `snapshot_fast`、`snapshot_medium`、`snapshot_slow` | 按记录日期使用15、60、240三种衰减长度的收益估计 |
| `snapshot_turnover` | 按换手率对上述估计插值 |
| `snapshot_covariance_bridge` | 用上一节的 Q 调整股票内积，长度60的收益估计 |
| `snapshot_without_direct` | 上一方案排除直接出现的目标日收益后重新估计 |
| `snapshot_donor_innovation` | 保留目标日观测的估计减去排除后的估计 |
| `snapshot_closest_other_gap` | 最近一条其他记录距离当前记录多少交易日，没有其他记录时缺失 |
| `snapshot_prior_mean` | 先用上一节的 `mean` 估计收益，再拟合历史残差并加回目标日修正 |

最后一列的具体做法是从各历史观测中减去股票设计矩阵乘 `mean`，把剩余部分交给同一个岭回归函数，最后加上目标日股票设计向量乘 `mean`。

## 7. _overlap()：直接出现过的目标日收益，共7列

查找当前日期之后1至20个交易日的同一策略记录。若一条后续记录比当前日期晚 gap 个交易日，则它的历史列 `20-gap` 正好对应当前目标日。gap 表示这两条记录的市场交易日间隔。

例如当前下标100的目标日是101，后续下标105的记录历史覆盖86至105日，第15号历史列就是101日。

若找到多次，按后续记录距离当前日期的远近加权，长度为10，生成下列列值：

| 配置名称 | 内容 |
|---|---|
| `overlap_mean` | 加权平均收益 |
| `overlap_nearest` | 最近一条后续记录报告的收益 |
| `overlap_median` | 中位数 |
| `overlap_dispersion` | 加权标准差 |
| `overlap_count` | 有值次数 |
| `overlap_closest_gap` | 最近一次出现的交易日间隔 |
| `overlap_sign_consistency` | 收益符号的加权平均再取绝对值，正负号越一致越接近1 |

收益符号取 −1、0、1。找不到有值观测时，次数为0，其余6列为缺失。

## 8. features()：补充历史统计并组成112列

前面 `signals()` 产生34列，直接收益统计产生7列，再依次填入以下内容。

| 零起始列位置 | 内容 |
|---|---|
| 0至33 | 第3至6节的34列 |
| 34至40 | 第7节的7列 |
| 41至60 | 当前20日策略收益，除以策略尺度，配置名 `return_20` 至 `return_1` |
| 61至80 | 当前20日带符号成交量，截到 −10 至10，配置名 `flow_20` 至 `flow_1` |
| 81至82 | 换手率和换手率对数，对数输入下限为十万分之一 |
| 83至91 | 最近5、10、20日的收益均值、收益标准差、成交量均值，每档3列 |
| 92至109 | 9种收益估计在同日同组中的均值和排名，每种2列 |
| 110至111 | 策略编号 `allocation`、市场组别 `group` |

成交量滚动均值切片为 `-window:-1`，所以名为5、10、20日的三个窗口实际平均4、9、19个值，均排除最新一天。

组内统计选择的9列是 `current_ridge_07`、`local_constant`、`local_daily_medium`、`local_adaptive_daily`、`long_ridge`、`long_covariance_prior`、`long_diagonal_prior`、`snapshot_covariance_bridge`、`snapshot_prior_mean`。

例如同日同组有3个策略，某种收益估计为 `[0.2,-0.1,0.5]`，则该种估计的组内均值列均为0.2，排名列依次为 `[0.5,0,1]`。排名由排序位置除以“组内记录数减一”得到，只有一行时为0，并列值按排序顺序分配位置。

结果按输入行位置写入，最后把非有限数值转成缺失值。

## 9. SharedSparsePrior：估计股票重要性后生成15列

### 9.1 estimate() 的输入筛选

本类从同组策略的当前20日历史估计股票重要性。先保留至少80%策略有值的历史日，再保留这些日期全部有值的策略。少于8个历史日或4条策略时，返回全为1的股票重要性和噪声强度0.7。

有效时，股票设计矩阵除以股票数平方根，策略收益逐列除以均方根，下限0.1。初始化股票重要性为1，噪声强度为0.7，随后交替更新24次。

### 9.2 股票重要性与噪声的交替更新

令 H 为筛选后的股票设计矩阵，Y 为调整尺度后的策略收益矩阵，m 为策略列数。定义 C=YYᵀ/m，表示历史日之间的策略收益乘积。令 γⱼ 为第 j 只股票的重要性，η 为噪声强度，I 为与历史日数量相同阶数的单位矩阵，hⱼ 为 H 的第 j 列。

每步先计算：

$$
A=(H\operatorname{diag}(\gamma)H^{\mathsf T}+\eta I)^{-1},\qquad z_j=Ah_j.
$$

`diag` 将向量放在对角线上。股票重要性更新为：

$$
\widetilde\gamma_j=\gamma_j\sqrt{\frac{\max(z_j^{\mathsf T}Cz_j,10^{-12})}{\max(z_j^{\mathsf T}h_j,10^{-9})}},\qquad
\gamma_j\leftarrow\operatorname{clip}(0.5\gamma_j+0.5\widetilde\gamma_j,10^{-4},20).
$$

`clip` 将结果限制在给定上下界。再令 r 为噪声更新比值，tr 表示迹：

$$
r=\frac{\operatorname{tr}(ACA)}{\operatorname{tr}(A)},\qquad
\eta\leftarrow\operatorname{clip}\left(0.5\eta(1+\sqrt{\max(r,10^{-12})}),0.015,4\right).
$$

γ 越大的股票，在随后的收益重建中获得越大的内积权重。这个类的系数由当前历史收益估计。

### 9.3 features() 的15列输出

调用 `panel(..., expanded=True)` 取行情，再将每只股票收益乘以其重要性的平方根。当前池选择由 `data.py` 决定。

| 配置名称 | 内容 |
|---|---|
| `sparse_current` | 当前20日拟合，岭系数使用估计的噪声强度 |
| `sparse_current_fixed_noise` | 当前20日拟合，岭系数固定0.7 |
| `sparse_local_fast`、`sparse_local_slow` | 拼接附近历史，时间衰减长度30、100的收益 |

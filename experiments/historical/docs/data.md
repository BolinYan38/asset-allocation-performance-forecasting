# data.py：整理真实日期、采样记录和股票行情

我们在本模块中将原始记录、日期映射和股票行情整理为收益重建所需的数组。`AllocationData` 管理这些输入，`FeatureDataset` 保存最终特征及其标签、行号和划分。

## 1. 入口与执行顺序

```python
data = AllocationData(data_dir, official=False)
raw = data.sample(offset=0, validation=True)
public, values, positions, row_map = data.panel(raw, group=1)
```

`data_dir` 是原始数据目录，`official` 表示是否载入官方测试记录，`offset` 是采样偏移，`validation` 表示是否采用本地验证划分，`group` 是市场组编号。

常规特征计算从初始化进入 `sample()`，再调用 `panel()`。学习股票先验时改用 `dated()` 取出所有已定位记录，用 `allowed_labels()` 选择可训练的标签，再调用 `panel()`。

## 2. 初始化输入

| 输入 | 读取后的属性 | 用途 |
|---|---|---|
| 原始训练记录及收益标签，可选的官方测试记录 | `raw` | 保存每条策略记录的20日历史与身份 |
| `assets/config.json` | `config` | 采样间隔、验证分界日、特征名和模型参数 |
| `assets/calendar.json` | `calendar` | 匿名日期名称对应的真实日期候选列表 |
| `assets/market.npz` | `market` | 各市场交易日和股票收益数组 |

`ASSETS` 是本方法的 `assets/` 目录，`RESULTS` 是 `runs/` 目录。`sessions` 从行情字典的 `sessions_1` 至 `sessions_4` 取出四组交易日，并转为日期字符串。

### 2.1 建立真实日期数组

`real_dates` 的位置与 `raw.date_names` 一一对应。一个匿名日期只有一个候选时，保存该候选；候选数不为1时，保存标记字符串 `9999-01-01`。

例如，按匿名日期编号0、1、2排列的候选是：

```python
[["2013-11-29"], ["2013-12-02", "2013-12-09"], ["2013-12-03"]]
```

则 `real_dates` 是：

```python
["2013-11-29", "9999-01-01", "2013-12-03"]
```

### 2.2 策略收益尺度

`scales` 每个策略一个数。先对每条原始训练记录的20日历史收益平方，忽略缺失值后取均值，再按策略累加，除以该策略的记录数，最后开平方。

设策略编号为 a，它在原始训练数据中的记录集合为 Rₐ，记录数为 nₐ。第 r 条记录有值的历史日集合为 Oᵣ，收益为 yᵣᵢ，其中 i 表示历史列。策略尺度 sₐ 为：

$$
s_a=\max\left(10^{-6},\sqrt{\frac1{n_a}\sum_{r\in R_a}\frac1{|O_r|}\sum_{i\in O_r}y_{ri}^2}\right).
$$

竖线表示集合元素数。历史收益在面板中除以这个尺度，股票先验训练时目标收益也除以同一尺度。这里使用原始训练来源标记，因此验证分界日之后的原始训练记录也参与历史尺度估计。

## 3. 选择记录和可用标签

### 3.1 subset()

`subset(raw, rows)` 用行位置数组 `rows` 切出逐行字段，保留原有日期名称表和策略名称表。例如取原始第3、8行后，两行仍使用全局匿名日期编号。

### 3.2 dated()

`dated()` 选出 `real_dates[raw.dates]` 不等于未定位标记的行，返回两个对象：切出的记录，以及这些记录在原始数据中的行位置 `original`。

例如 `original=[3,8]`，那么返回数据中的第1行对应原始第8行。股票先验模块通过它将计算结果写回原始行位置。

### 3.3 allowed_labels()

官方模式采用全部原始训练标签。验证模式还要求记录的真实日期严格早于配置分界日，当前为 `2013-12-02`。

例如，已定位到 `2013-11-29` 的训练记录可用于验证阶段拟合，`2013-12-02` 当天的训练记录属于验证侧。日期未定位的记录在 `dated()` 中被过滤，验证模式下也不能通过日期比较。

## 4. sample()：按联合交易日采样

先合并各市场交易日并排序去重，得到 `union`。只要有一个市场当天开市，该日期就在这张表中。

`stride` 是采样间隔，当前为21。分界日在 `union` 中的插入位置除以21取余，得到 `phase`。采样语句为：

```python
clock = union[(phase + offset) % stride::stride]
```

`clock` 保存本轮采样日期。假设分界日在联合日期表中的下标为100，则 `phase=16`。偏移0选下标16、37、58、79、100等，偏移5选0、21、42、63、84、105等。

接着选择真实日期落在 `clock` 上的匿名日期，再取这些日期的全部策略记录。官方模式额外并入全部官方测试匿名日期。验证模式把采样记录的 `train_mask` 重新设为“真实日期早于分界日”。

当前四个偏移为0、5、10、15。后续流程在偏移0保留训练及查询行，其余偏移只保留训练行，见 [pipeline.md](pipeline.md)。

## 5. panel()：变成日期与策略组成的数组

### 5.1 选市场、排序、确定位置

按 `raw.groups == group` 取行。`allocations` 保存这些行涉及的策略编号，`dates` 保存按真实日期排序的匿名日期编号。`positions` 用这些真实日期查市场交易日表，保存对应下标。

当前股票池选择语句为：

```python
key = "expanded_returns_3" if expanded and group == 3 else f"returns_{group}"
```

因此 `expanded=True` 时第3组取扩展股票池，其余组取各自的基础股票池。

### 5.2 固定每个策略的列位置

设选出的日期数为 D、策略数为 S，则创建：

| 数组 | 形状 | 初值及含义 |
|---|---|---|
| `values` | D × 20 × S | 初值缺失，保存标准化策略历史 |
| `row_map` | D × S | 初值 −1，保存对应输入记录的行位置 |

代码用 `date_index` 将全局匿名日期编号转成当前日期行号，用 `searchsorted(allocations, ...)` 将全局策略编号转成当前策略列号，再一次性填入数据。

例如两天有策略甲、乙，但第二天缺少乙，记录行位置依次为0、1、2，则：

```python
row_map = [[0, 1], [2, -1]]
```

`values[0, :, 0]` 是第一天策略甲的20日历史，`values[1, :, 1]` 则保持缺失。

### 5.3 标准化股票收益并返回

`LAGS=[19,18,...,0]`。若某日期的市场交易日下标为100，`100-LAGS` 就取81至100的20日股票收益，目标日使用下标101。

`history` 标记当前输入中包含训练行的日期。取这些日期的20日股票窗口，合并后逐股票计算标准差，下限为0.005。每只股票的完整行情除以自身标准差，作为 `public` 返回。

返回顺序固定为：

```text
public     市场交易日 × 股票，标准化后的股票收益
values     快照日期 × 20个历史日 × 策略，标准化后的策略收益
positions  每个快照日期在市场交易日表中的下标
row_map    快照日期 × 策略，对应输入行位置
```

窗口中重复出现的股票历史日会重复参与标准差计算。股票尺度由本次传入的记录及其训练标记决定。

## 6. FeatureDataset：保存最终训练材料

| 字段 | 内容 |
|---|---|
| `features` | 每条记录的130列特征 |
| `row_ids` | 比赛原始行号 |
| `targets` | 目标日策略收益 |
| `train_mask` | 当前阶段用于分类器训练的行 |
| `groups` | 市场组编号 |
| `dates` | 匿名日期编号 |

`save()` 将六个字段及特征名称 `feature_names` 写入压缩文件。`load()` 按数据类声明的六个字段恢复对象。分类器通过这些标记选取训练行与查询行。
